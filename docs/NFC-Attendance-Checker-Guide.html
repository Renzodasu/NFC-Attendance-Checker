NFC Attendance Checker

How to use it · offline, one phone, no accounts

A student taps their ID card once to join a class roster, then taps it again to be marked present. Everything stays on this phone; the only thing that ever leaves it is the .xlsx file you export yourself.

The four tabs

1 · Sections

  • Create one section per class (e.g. BSCE-4B). Each keeps its own roster.
  • The green card is the section you are working in - tap another to switch.
  • Date updated moves only when the roster really changes, so an untouched section keeps its date.

2 · Register

  • Tap Start registering, then hold a student's ID to the phone.
  • Type the name and press Save - it goes straight into the selected section.
  • The same card tapped again updates that student instead of adding a second row.

3 · Scan

  • Tap Start session, then tap each student's ID once.
  • A card read twice inside 3 seconds counts once.
  • The bar at the bottom shows the live count: present, absent, unmatched.

4 · Report

  • The absent list is the conclusion - it is the short list you act on.
  • Present and unmatched taps are supporting data; unmatched means a card that is not on this roster.
  • Export the whole session as one Excel file.
How it flows
Step by step
1

Make your class section

Open Sections, type the section name in New section name and press Create section. It becomes the selected section right away.

2

Register the students

Open Register and press Start registering. Hold a student's ID to the back of the phone, type their name, press Save. Repeat for the class, then press Stop registering. Already registered? The card shows the name it is already filed under - saving just renames that row.

3

Take attendance

Open Scan and press Start session. Tap each student's ID once. The session bar keeps the running score and you can switch tabs while it counts.

4

Fix a name or remove a card

In Sections, the selected section lists every registered student. The pencil renames, the bin removes - removing a card is the only way to free a UID for someone else.

5

Read the result

Open Report. Read the absent list first, then check the unmatched taps: a card that is not on this roster is flagged, never silently dropped.

6

Export to Excel

Sections exports the roster (with the section name and the date it last changed). Report exports the session (Absent, Present, Unmatched in that order). Both land in Documents/NFC Attendance and a Share this .xlsx button appears.

7

Load a section a classmate sent you

On Sections, press Import section from .xlsx, pick the file they exported, check the preview, then Import. It merges by card UID: nobody is deleted, the same card never appears twice, and a name in the file wins over yours. The later of the two dates is kept.

If something looks off

The UID does not match

Phones report the same card in one of two byte orders. On Register or Scan, look at UID byte-order check: tap a card, compare the as-read and reversed columns with what your roster shows, and tick Reversed UID byte order if the reversed column is the one that matches.

Your data

A card UID alone is a hardware serial; once it is joined to a name it identifies a person (RA 10173). That mapping lives only in this app's private storage - no server, no account, no internet permission. Exported files go to the shared Documents folder, where other apps can read them: delete them when the class no longer needs them.
